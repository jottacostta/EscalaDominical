# Protótipo UX mobile — EscalaDominical

## Objetivo
Prévia isolada para avaliação visual do painel inicial, com foco em celular e em tornar ações e pendências fáceis de entender.

## Base consultada
- `Escala_de_Setores_V330.html`
- `Escala_2x1_encarregados_V204.html`
- `AGENTS.md` — especialmente a regra de ouro UX/UI e a seção 4.1.

## Importante
Esta pasta é um protótipo visual independente, não uma nova versão funcional dos aplicativos. Os números são fictícios. Os botões levam aos aplicativos oficiais ou mostram uma orientação; não geram escala, não alteram regras e não gravam histórico. Não contém dados de funcionários.

## Escopo desta etapa
- painel inicial responsivo;
- alternância visual entre Setores, Encarregados e Histórico;
- ações principais em alvos grandes;
- avisos em texto, com orientação para o próximo passo;
- indicação explícita de que os números são demonstrativos.

## Limitação técnica
O conector GitHub permitiu identificar os arquivos e seus SHAs, mas não devolveu o conteúdo dos HTMLs grandes (2,1 MB e 1,47 MB). Por isso, esta entrega não afirma ser uma cópia integral dos arquivos atuais: é uma prévia independente inspirada na estrutura documentada. Antes de integrar qualquer alteração aos aplicativos reais, é necessário obter os HTMLs completos, comparar as telas atuais e aplicar mudanças mínimas em uma cópia de trabalho.

## Aprovação e segurança
Nenhum merge foi feito. Nenhum arquivo da `main` foi alterado. Este branch existe somente para avaliação. A integração funcional só deve começar depois da aprovação explícita do gerente do projeto.
