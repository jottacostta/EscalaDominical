# EscalaDominical
Projeto escala de setores — Supermercados Guanabara.

Cada arquivo `.html` é o app completo: é só abrir no navegador (funciona sem internet).

| Arquivo | O que é |
|---|---|
| `Escala_de_Setores_V209.html` | **Versão atual** da Escala de Setores |
| `Escala_2x1_encarregados_V151.html` | **Versão atual** da Escala de Encarregados |
| V204–V208 / V150 | versões anteriores, guardadas para comparação |

O histórico de mudanças de cada versão fica no comentário `HISTÓRICO DE VERSÕES` no topo de cada arquivo.
