# EscalaDominical
Projeto escala de setores — Supermercados Guanabara.

Cada arquivo `.html` é o app completo: é só abrir no navegador (funciona sem internet).

| Arquivo | O que é |
|---|---|
| `Escala_de_Setores_V215.html` | **Versão atual** da Escala de Setores |
| `Escala_2x1_encarregados_V158.html` | **Versão atual** da Escala de Encarregados |
| V204–V214 / V150–V157 | versões anteriores, guardadas para comparação |

O histórico de mudanças de cada versão fica no comentário `HISTÓRICO DE VERSÕES` no topo de cada arquivo.

O histórico de cada mês é guardado em `Historico_<Setor>_<mês>_<ano>.json` (ex.: `Historico_Frente_de_Loja_11_2026.json`). No mês seguinte, abra esse arquivo em ⋮ → Abrir histórico guardado.
